# GIT Marketplace - Service Booking Platform

A full-stack marketplace connecting drivers and service providers with customers in Palakkad, India.

## 🚀 Features

- **User Authentication** - Signup/Login for Drivers and Customers
- **Job Marketplace** - Drivers see available jobs and accept them
- **Real-time Job Updates** - Jobs update instantly when accepted
- **Commission Model** - Platform earns 20% on each transaction

## 🛠️ Tech Stack

- **Frontend:** Next.js 14, React, Tailwind CSS
- **Backend:** Next.js API Routes, Supabase
- **Database:** PostgreSQL (Supabase)
- **Payments:** Razorpay (integrated)
- **Deployment:** Vercel

## 👨‍💻 How to Run

1. Clone: `git clone https://github.com/musthaqahmedg/git`
2. Install: `npm install`
3. Setup Supabase & Razorpay keys in `.env.local`
4. Run: `npm run dev`
